# 100Hires LinkedIn B2B Organic Strategy Research

This repository contains a research-backed playbook for building a B2B LinkedIn presence through organic content.

The main deliverable is the [B2B LinkedIn Organic Growth Playbook](PLAYBOOK.md), built from practitioner research collected in the `research/` folder.

## What This Project Covers

- How B2B founders, operators, and consultants use LinkedIn organically
- What post formats, hooks, and positioning patterns appear repeatedly
- Where practitioners disagree on tactics like gating resources, post length, and AI usage
- Which tactics were rejected because they are weak, misleading, or hard to repeat
- Original ideas for turning LinkedIn posting into a measurable research loop

## Main Files

- [PLAYBOOK.md](PLAYBOOK.md) - Final SOP and analysis for B2B LinkedIn organic growth
- [research/sources.md](research/sources.md) - Expert source list and annotations
- [research/linkedin-posts/](research/linkedin-posts/) - Collected LinkedIn post examples
- [research/other/](research/other/) - Supporting research and non-LinkedIn references

## Research Method

The research focuses on 10 practitioners who actively use LinkedIn, not passive commentators. Each source was chosen because they either run a company, advise clients, build an audience, or publish from direct operating experience.

The collected material is LinkedIn-first by design. No paid distribution strategy, YouTube strategy, podcast strategy, or newsletter strategy is treated as the main scope.
